# 燧引（Suì Yǐn）

> 燧石擦出火星，引燃远程控制。

一款基于蓝牙的 Android 远程控制工具——用一台手机控制另一台手机的热点、短信、媒体播放。无需网络，蓝牙直连，硬核且纯粹。

## ✨ 它能做什么

| 功能 | 一句话说明 |
|------|-----------|
| 🔥 **热点控制** | 远程开关 Wi-Fi 热点。支持双网卡设备（WiFi 和热点同时在线） |
| 💬 **短信同步** | 在主机查看被控机所有短信，直接在主机回复和发送新短信 |
| 🎵 **媒体控制** | 远程播放 / 暂停 / 切歌，实时同步播放状态 |
| 📶 **状态监控** | 实时显示被控机电量、信号强度、网络状态 |
| 🌐 **网络开关** | 远程开关 Wi-Fi 和移动数据 |

## 🚀 快速开始（5 分钟上手）

### 第一步：准备

- 两台 Android 手机（Android 8.0+）
- 两台手机通过蓝牙配对好
- **被控机建议 Root**（MIUI 控制热点必需）

### 第二步：安装

1. 下载 APK 装到两台手机上
2. 打开 App，会让你选择模式：
   - **主机**：用来控制别人的那台
   - **被控机**：被控制的那台

### 第三步：连接

**被控机端：**
1. 选择"被控机"进入
2. 点击"开启被控"
3. 一路同意所有权限请求（短信、通知、蓝牙……都给它）
4. 保持 App 在前台（或者允许后台运行）

**主机端：**
1. 选择"主机"进入
2. 点击"扫描设备"，找到你的被控机
3. 点一下连接，连上了就可以开搞了

### 第四步：开搞

底部四个 Tab：
- **首页**：快捷操作（热点、WiFi、数据、状态）
- **短信**：查看和发送短信
- **媒体**：远程控制音乐
- **设置**：杂项

## 🔑 权限说明

| 权限 | 谁需要 | 用来干嘛 | 不给会怎样 |
|------|--------|---------|-----------|
| 蓝牙权限 | 都要 | 设备发现和通信 | 连不了 |
| 短信权限 | 被控机 | 读取短信内容、发送短信 | 短信功能用不了 |
| 通知访问 | 被控机 | 监听媒体播放状态 | 媒体控制用不了 |
| Root 权限 | 被控机 | MIUI 上控制热点 | 热点开不了（关可以） |
| 通知权限 | 都要 | 前台服务保活 | 容易被系统杀掉 |

## 🔥 热点控制那些事

### MIUI 手机为什么要 Root？

MIUI 把热点控制的权限锁得很死，普通 App 根本开不了热点。Root 后用 `cmd wifi start-softap` 命令才能正常工作。

### 双网卡是什么？

有些手机（比如小米的部分机型）有双网卡，可以一边开热点一边连 WiFi。燧引支持这种模式——开热点不会关掉你的 WiFi。

单网卡的手机就没办法了，开热点系统会自动关 WiFi，这是 Android 的正常机制。

### 热点开不了怎么办？

1. 确认被控机已经 Root，并且给了燧引 Root 权限
2. 在被控机的 SlaveActivity 里点"测试"按钮，看详细错误信息
3. 用 `adb shell su -c 'cmd wifi start-softap TestAP wpa2 test123456'` 手动试试能不能开

## 🔧 自己编译

### 环境要求

- **JDK 17**（必须 17，高了低了都可能出问题）
- **Android SDK**（API 33+）
- **Gradle 8.2**（项目自带 wrapper，不用手动装）

### Windows 一键编译

编辑 `build.bat`，把里面的 `SDK_DIR` 和 `JAVA_HOME` 改成你自己的路径，然后双击运行。

### 命令行编译

```bash
# 设置环境变量
set ANDROID_HOME=你的SDK路径
set JAVA_HOME=你的JDK17路径

# 编译 debug APK
gradlew assembleDebug
```

编译好的 APK 在：`app/build/outputs/apk/debug/app-debug.apk`

### 国内镜像

项目里 gradle 用的是阿里云镜像，下载速度快。如果你想换别的，改 `gradle/wrapper/gradle-wrapper.properties` 里的 `distributionUrl`。

## ❓ 常见问题

**Q：两台手机连不上？**
A：先确认蓝牙配对好了，再确认两台都开了 App，被控机点了"开启被控"。

**Q：热点能关不能开？**
A：MIUI 必须 Root。Root 后还是不行的话，在被控机 SlaveActivity 点"测试"看报错。

**Q：短信不显示？**
A：确认被控机给了短信权限，并且通知权限也开了。

**Q：App 在后台就断连？**
A：给 App 加电池优化白名单，允许后台运行。被控机有前台服务通知，尽量别划掉。

**Q：可以同时控制多台被控机吗？**
A：目前是一对一的，一台主机连一台被控机。
