# 燧引（Suì Yǐn）

> 燧石擦出火星，引燃远程控制。

一款基于蓝牙的 Android 远程控制工具，让你用一台手机控制另一台手机的热点、短信、媒体播放等功能。

## ✨ 命名由来

**燧** —— 燧石取火，摩擦生热。开热点就像点火，一点即燃。
**引** —— 引出、引导。从被控端引出短信列表，引导媒体播放，控制的核心是"引"。

比单纯的"燧石"多了动作感，更贴合远程控制的本质。

## ⚡ 功能特性

| 功能 | 说明 |
|------|------|
| 🔥 **热点控制** | 远程开关 Wi-Fi 热点，支持双网卡设备（WiFi 和热点同时在线） |
| 💬 **短信同步** | 在主机查看被控机的短信列表，支持直接在主机发送短信 |
| 🎵 **媒体控制** | 远程播放/暂停/切歌，同步当前播放状态 |
| 📶 **状态监控** | 实时查看被控机电量、信号强度 |
| 🔌 **Wi-Fi/数据** | 远程开关 Wi-Fi 和移动数据 |

## 📱 使用说明

### 准备工作

- 两台 Android 手机（被控机建议 Root，MIUI 必备）
- 两台手机已通过蓝牙配对

### 安装

1. 在两台手机上都安装 APK
2. 打开 App，分别选择**主机**或**被控机**模式

### 连接

1. **被控机**：打开 App，点击"开启被控"，授予所需权限
2. **主机**：打开 App，在设备列表中选择被控机
3. 连接成功后即可开始远程控制

### 权限说明

| 权限 | 用途 |
|------|------|
| 蓝牙权限 | 设备发现与通信 |
| 短信权限 | 读取/发送短信 |
| 通知访问 | 监听媒体播放状态 |
| Root 权限 | MIUI 上控制热点必需 |
| 通知权限 | 前台服务、状态通知 |

### 热点控制说明

- **MIUI 设备**：必须 Root，使用 `cmd wifi start-softap` 命令控制
- **双网卡设备**：WiFi 和热点可同时工作，不会互相干扰
- **单网卡设备**：开热点时系统会自动关闭 WiFi，属正常现象

## 🔧 构建

### 环境要求

- JDK 17+
- Android SDK (API 34)
- Gradle 8.2

### 编译

```bash
# Windows
build.bat

# 或直接用 gradle
./gradlew assembleDebug
```

APK 输出位置：`app/build/outputs/apk/debug/app-debug.apk`

## 📁 项目结构

```
app/src/main/
├── java/com/tool/btremote/
│   ├── network/          # 网络控制（热点/WiFi/移动数据）
│   ├── service/          # 核心蓝牙服务
│   ├── ui/               # 界面（主机/被控/主入口）
│   ├── sms/              # 短信接收与管理
│   ├── media/            # 媒体监听与控制
│   ├── common/           # 公共工具
│   └── App.kt            # Application 入口
├── res/                  # 资源文件
└── AndroidManifest.xml   # 清单文件
```
